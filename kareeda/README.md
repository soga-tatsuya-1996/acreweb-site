# kareeda（カレエダ）— 公式サイト

岡山市北区京橋町のカレー店「kareeda（カレエダ）」の Web サイト（静的サイト）。
コンセプトは「カレーとお酒とデザートと」。

## 構成

```
kareeda/
├── index.html            … 1ページ完結のサイト本体
├── assets/
│   ├── css/style.css     … スタイル（配色・レイアウト）
│   ├── js/main.js        … ヘッダー追従・スマホメニュー・スクロール演出
│   └── img/              … 写真を入れる場所（現在は空）
└── README.md
```

ビルド不要。`index.html` をブラウザで開くだけで表示できます。
ローカル確認用サーバー（任意、`WebSite/` で実行）:

```bash
python -m http.server 8000
```

→ ブラウザで <http://localhost:8000/kareeda/> を開く。

## ギャラリー（Instagram 埋め込み）

`#gallery` セクションは **Instagram 公式の埋め込み**（`embed.js`）で投稿を表示しています。
投稿を差し替えるには、`index.html` の `<div class="ig-grid">` 内にある `<blockquote class="instagram-media" …>` の
`data-instgrm-permalink` を、表示したい投稿の URL（`https://www.instagram.com/p/＜投稿ID＞/`）に書き換えます。

> 現在掲載しているのは、制作時点（2026-10-11）の最新 6 投稿です。
